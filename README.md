# Student Record Management

This repository contains the initial backend scaffold for the School Student Record Management System.

## Stack

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Alembic
- JWT authentication

## Structure

The project is organized into a modular backend with shared models, schemas, API routes, services, and repositories.

## Notes

This is the initial scaffold only. Business logic and feature implementation will be added in subsequent development steps.
